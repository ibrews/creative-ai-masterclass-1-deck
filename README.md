# Creative AI Workflow Masterclass, Part 1: Set Up From Scratch

The class deck for Creative AI Workflow Masterclass, Part 1 — Alex Coulombe Presents

**▶ View the deck:** https://ibrews.github.io/creative-ai-masterclass-1-deck/

Built on [Spatial Deck](https://github.com/ibrews/spatial-deck), the single-file HTML presentation framework.

## Quickstart

```bash
git clone https://github.com/ibrews/creative-ai-masterclass-1-deck && open creative-ai-masterclass-1-deck/index.html
```

## Things to Try

1. Open `index.html` and press → to step through the talk.
2. Press **N** for presenter notes, or open `index.html?notes` on a phone.
3. Open `index.html?edit` and press **M** for move mode to reposition anything.
4. Try another look: `index.html?look=swiss` (or folio, memo, atlas…). See them all in `styles/index.html`.
