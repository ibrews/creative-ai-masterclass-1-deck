# Creative AI Workflow Masterclass, Part 1: Set Up From Scratch

The slides for **Creative AI Workflow Masterclass, Part 1**, a live class by [Alex Coulombe Presents](https://alexcoulombepresents.com/classes/2026-11-04-creative-ai-masterclass-part-1) (Thursday, November 5, 2026, 12p ET; moved from Wednesday). Go from nothing to a working creative AI setup: one assistant you trust, connected to your tools over MCP, with a memory that carries from one session to the next.

**▶ View the deck:** https://ibrews.github.io/creative-ai-masterclass-1-deck/

Built on [Spatial Deck](https://github.com/ibrews/spatial-deck), the single-file HTML presentation framework.

## Quickstart

```bash
git clone https://github.com/ibrews/creative-ai-masterclass-1-deck
cd creative-ai-masterclass-1-deck
python3 -m http.server 8750   # then open http://localhost:8750/
```

Opening `index.html` directly also works. Edit the `SECTIONS` array near the top of `index.html`.

## What is in it

| Chapter | What it covers |
|---|---|
| 1 · Start with one assistant | A private folder as its home; knowledge is not permission |
| 2 · Connect it to your tools | How MCP works; start read-only (Unreal, Blender, Godot) |
| 3 · Give it a memory | The project-memory note, and the recipe, job, change, inspect, save loop |
| Homework | Build the fictional gallery, change one thing, restart the assistant |

## Things to Try

1. Open the deck and press **→** to step through it; chapter 1 opens on "Start With One Assistant."
2. Press **N** for speaker notes on any slide.
3. Open `index.html?notes` on a phone to use it as a presenter remote view.
4. Try another look with `index.html?look=swiss` (browse them in `styles/index.html`).
