Read only. Begin in the project's Brain directory and locate a relevant Markdown page. Open the actual page. Read its document ID, review status, supported environment and the passage that answers the question. For a question about this exhibition, open Studio/show-brief.md and cite its brief ID separately.

Choose the starting file by the question:
- A nickname, accepted checkpoint or private decision: Studio/project-memory.md.
- The wall code, route or tower heights: read Studio/show-brief.md directly.
- A first build or title edit: Brain/workflows/part-1-exercise.md.
- A fresh chat: Brain/start-here/resume-after-restart.md.
- An interrupted build: Brain/troubleshooting/recover-an-interrupted-job.md.

For a mixed question read each applicable file before answering. Answer under three headings: Course source, Answer, and What to check locally. Include the exact document ID and relative file path. Distinguish course instructions from observations about the learner's files. If the sources do not specify the answer, say which detail is missing. Never invent a receipt, run a command, or change files as part of this skill.
